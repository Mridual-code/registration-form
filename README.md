# User Registration Form

## Project Description

This project is a User Registration Form built using React. It demonstrates form handling, state management, and client-side validation using React Hooks.

The application allows users to enter their Name, Email, Password, and Confirm Password. The form validates user input before submission and displays appropriate error messages when validation rules are not met.

## Features

- User Registration Form
- Controlled Components using React State
- Required Field Validation
- Email Format Validation
- Password and Confirm Password Matching Validation
- Dynamic Error Messages
- Responsive and User-Friendly Interface

## Concepts Used

- React Functional Components
- useState Hook
- Form Handling
- Controlled Inputs
- Event Handling
- Conditional Rendering
- Client-Side Validation

## Validation Rules

- All fields are mandatory.
- Email must follow a valid email format.
- Password and Confirm Password must match.
- Validation messages are displayed for invalid inputs.

## Outcome

This project demonstrates how to build interactive forms in React, manage user input efficiently, and perform real-time validation to improve user experience.
